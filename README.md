# NOVA RP AI — Discord-бот помощник

AI-помощник для GTA RP проекта **NOVA RP**. Бот собирает знания с форума
[forum.grand-rp.su](https://forum.grand-rp.su) (XenForo), индексирует правила и жалобы и отвечает
игрокам **кратко, по-русски и только по данным форума** — со ссылками на источники.

- Node.js 22.13+ · discord.js v14 · TypeScript
- База данных — встроенный `node:sqlite` (без нативных модулей → работает в **Termux** на Android)
- Парсинг форума — `cheerio`; AI — OpenAI / Google Gemini / Anthropic Claude / Groq / Mistral / DeepSeek / xAI Grok / OpenRouter (через `fetch`, без SDK)

## Возможности

| Команда | Где | Что делает |
|---|---|---|
| `/setup` | сервер, админы | Создаёт категорию **NOVA RP AI**: `#ai-помощник`, `#ai-правила` (обновления правил, только чтение), `#ai-настройки` (видно только админам), `#ai-логи`. Повторный запуск дублей не создаёт — предлагает восстановить недостающее |
| `/setupls` | ЛС (или сервер → меню придёт в ЛС) | «Мои серверы», «Личный токен», «Личные настройки» |
| `/вопрос <текст> [скрытно]` | сервер, ЛС | Вопрос к AI |
| `/правило <номер>` | сервер, ЛС | Текст пункта и наказание, например `/правило 5.4` (с автодополнением) |
| `/наказание <пункт>` | сервер, ЛС | Наказание и даёт ли повтор **WARN** |
| `/жалоба` | сервер, ЛС | Модальное окно → готовый текст жалобы по форме форума + проверка пункта, даты (48 ч), хостинга доказательств |
| `/faq [вопрос]` | сервер | Быстрые ответы администрации (приоритет над AI) |
| `/мой-id добавить / удалить / список` | сервер, ЛС | Привязать свой игровой ID: бот упомянет вас в `#ai-жалобы` (и напишет в ЛС), если на форуме подадут жалобу на этот ID или сменится её статус |
| `/clean [канал] [количество] [сообщение]` | сервер, ЛС | Удалить сообщения **бота** (меню, обновления правил, журнал и закреплённые остаются). С параметром `сообщение` (ID или ссылка) — удалить именно это сообщение, даже защищённое |
| `/помощь` | везде | Список команд |

Кроме команд: в `#ai-помощник` и в ЛС боту можно просто писать вопрос. Упоминание бота в другом канале работает,
если у роли есть право «В любом канале».

### Меню `#ai-настройки` (и «Мои серверы» в `/setupls`)
1. **Роли** — создать роль (название через Modal) или выбрать существующую; права:
   задавать вопросы · любой канал / только `#ai-помощник` · источники форума · AI-токен и модель · логи · лимит вопросов в час.
2. **AI-токен** — провайдер, токен **только через Modal**, хранение в **AES-256-GCM** (ключ из `.env`),
   показ в маскированном виде (`sk-...a1b2`), кнопка «Проверить токен», выбор модели из списка или своя модель.
3. **Источники** — добавить/удалить ссылки на темы (`/threads/…`) и разделы (`/forums/…`), интервал автообновления,
   кнопка «Обновить базу знаний».
4. **Каналы** — переназначить каналы, восстановить недостающие.
5. **FAQ** — быстрые ответы (вопрос, ответ, ключевые фразы).
6. **Статус** — источники, темы, фрагменты, пункты правил, последнее/следующее обновление, запросы к AI.

Права проверяются в реальном времени при каждом действии (в том числе из ЛС). Каждое изменение записывается в БД
(`audit_log`) и в `#ai-логи` (секреты не пишутся).

### Как отвечает AI (RAG)
1. Если вопрос совпал с **FAQ** — ответ из FAQ, AI не вызывается.
2. Если в вопросе есть номер пункта (`5.4`) — пункт берётся напрямую из базы правил.
3. Поиск **BM25** с русским стеммингом по фрагментам форума (только источники этого сервера).
4. Нет данных → бот честно говорит, что информации нет, и **AI не вызывается** (вопросы не о NOVA RP тоже отсекаются здесь).
5. Модель получает строгий системный промпт: только русский, только NOVA RP, только контекст, без выдумок,
   ссылки `[1]`; в конце ответа бот добавляет список источников.

Промпт подстраивается под модель (`src/ai/prompt.ts`):

| Стиль | Для кого | Особенности |
|---|---|---|
| `standard` | OpenAI, xAI Grok, OpenRouter (прочие) | Подробные нумерованные правила |
| `claude` | Anthropic, `anthropic/*` в OpenRouter | Контекст и вопрос в XML-тегах `<context>`, `<fragment>`, `<question>` |
| `gemini` | Google, `google/*` в OpenRouter | Запрет заголовков и вступлений — Gemini склонен к длинным ответам |
| `compact` | Groq, Mistral, DeepSeek, Llama/Qwen/Mistral в OpenRouter | Короткие правила, пример ответа, напоминание «отвечай на русском» в конце, temperature 0.1 |

«Думающим» моделям (o4-mini, deepseek-reasoner, gpt-oss, qwen3, grok-3-mini…) автоматически даётся больший
лимит токенов, а блоки `<think>…</think>` вырезаются из ответа.

### Мастер настройки и «Настройки AI»
- **🪄 Мастер настройки** (меню `#ai-настройки`) проверяет сервер — права бота, каналы, AI-токен и модель, источники,
  лимиты под число участников, роли модераторов — и применяет рекомендации одной кнопкой.
- **🧠 Настройки AI**: длина ответа по умолчанию, точность (temperature), объём контекста, «умный поиск»,
  показ источников и **свои инструкции** для AI (дополняют, но не отменяют основные правила бота).

### Уведомления о жалобах (`#ai-жалобы`)
Игрок привязывает свой игровой ID (`/мой-id добавить` или `/setupls` → «Мои игровые ID», до 3 ID; один ID — один
человек). Каждые `COMPLAINT_CHECK_MINUTES` минут бот смотрит первую страницу раздела «Жалобы на игроков», берёт
«ID нарушителя» из формы жалобы и, если он привязан, упоминает владельца в `#ai-жалобы` (и пишет в ЛС — можно выключить).
Также сообщает о смене статуса жалобы. Первый проход только запоминает темы — старые жалобы не рассылаются.

### Если форум включил защиту от ботов
Форум может показывать «Проверка браузера» вместо страниц. Бот открывает такую страницу в headless Chromium
(`playwright-core`) с тем же User-Agent, ждёт окончания проверки и дальше ходит обычными запросами с полученными cookie.
Браузер ставится один раз: `npx playwright install --only-shell chromium` (отключить: `FORUM_BROWSER_CLEARANCE=false`).
Если проверку пройти не удалось, бот **не удаляет** собранную базу — продолжает отвечать по ней, а в `#ai-логи`,
«Источниках» и Мастере появляется предупреждение.

### Канал `#ai-правила`
При каждом обновлении базы знаний бот сравнивает пункты в темах **правил** с прошлой версией и публикует:
🆕 новые пункты, ✏️ изменённые (отдельно видно смену наказания «было → стало»), 🗑 удалённые, 📄 новые темы правил.
Жалобы и прочие темы туда не попадают. Первая индексация ничего не публикует (нет спама старыми правилами).
Канал создаётся `/setup`; на уже настроенном сервере запустите `/setup` → «Восстановить недостающее»
или назначьте любой канал в меню «Каналы».

**Приватность:** при индексации жалоб ники, ID и контакты игроков заменяются на `[скрыто]` (в полях, тексте и
заголовке темы), авторы жалоб не сохраняются. Модель дополнительно проинструктирована не называть игроков.

### Вежливый сбор данных
Один запрос за раз, пауза `SCRAPE_DELAY_MS` (по умолчанию 2,5 с), собственный User-Agent, повтор с паузой при 429/5xx,
кэш в БД (жалобы без новых сообщений не скачиваются повторно), ограничение числа тем и страниц,
автообновление раз в N часов (по умолчанию 12, меняется в меню).

## 1. Discord Developer Portal

1. https://discord.com/developers/applications → **New Application** → назовите, например, `NOVA RP AI`.
2. **General Information** → скопируйте **Application ID** → это `DISCORD_CLIENT_ID`.
3. **Bot** → **Reset Token** → скопируйте токен → это `DISCORD_TOKEN` (никому не показывайте!).
4. **Bot → Privileged Gateway Intents** → включите **MESSAGE CONTENT INTENT**
   (нужен, чтобы читать вопросы в `#ai-помощник`). `Server Members` и `Presence` **не нужны**.
5. **Installation** →
   - *Installation Contexts*: отметьте **Guild Install** и **User Install**
     (User Install нужен, чтобы `/setupls` и вопросы работали в ЛС);
   - *Install Link*: **Discord Provided Link**;
   - *Default Install Settings → Guild Install*: scopes `bot`, `applications.commands`; права —
     **Manage Roles, Manage Channels, View Channels, Send Messages, Embed Links, Read Message History**.

### Приглашение бота на сервер
Готовая ссылка (замените `APP_ID` на Application ID):

```
https://discord.com/oauth2/authorize?client_id=APP_ID&scope=bot+applications.commands&permissions=268520464
```

`268520464` = Manage Roles + Manage Channels + View Channels + Send Messages + Embed Links + Read Message History.

> Роль бота на сервере должна стоять **выше** ролей, которые он создаёт/настраивает.

## 2. Запуск на телефоне (Termux, Android)

Termux ставьте из **F-Droid** или GitHub (версия из Google Play устарела).

```bash
pkg update && pkg upgrade -y
pkg install -y nodejs-lts git
node -v   # должно быть v22.13 или новее (подойдёт и пакет nodejs)
```

Скачайте проект и установите зависимости (нативных модулей нет — ничего не компилируется):

```bash
git clone https://github.com/<вы>/nova-rp-ai-bot.git
cd nova-rp-ai-bot
npm install
```

Настройте `.env`:

```bash
cp .env.example .env
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"   # → ENCRYPTION_KEY
nano .env
```

Заполните минимум `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `ENCRYPTION_KEY`.

Сборка, регистрация команд, запуск:

```bash
npm run build
npm run deploy          # глобальная регистрация slash-команд (появятся в течение нескольких минут)
npm start
```

Для быстрой проверки на одном сервере: укажите `DEV_GUILD_ID` и выполните `npm run deploy -- --guild`
(команды появятся сразу). Потом удалите их оттуда `npm run deploy -- --clear-guild`, чтобы не было дублей с глобальными.

Затем на сервере: `/setup` → `#ai-настройки` → **AI-токен** → выберите провайдера → «Ввести токен» → «Проверить токен».

### Как держать бота включённым

```bash
termux-wake-lock                 # не даёт Android усыпить Termux
npm install -g pm2
pm2 start ecosystem.config.cjs   # автоперезапуск при падении
pm2 save
pm2 logs nova-rp-ai              # логи
pm2 restart nova-rp-ai           # после обновления кода: git pull && npm install && npm run build
```

Также:
- в настройках Android отключите **оптимизацию батареи** для Termux;
- автозапуск после перезагрузки телефона — приложение **Termux:Boot**, файл `~/.termux/boot/start-bot.sh`:

  ```bash
  #!/data/data/com.termux/files/usr/bin/sh
  termux-wake-lock
  pm2 resurrect
  ```
  и `chmod +x ~/.termux/boot/start-bot.sh`.

## 2.1. Запуск на сервере (VPS, Linux) из GitHub

```bash
# Ubuntu/Debian: Node.js 22 LTS
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs git

git clone https://github.com/<вы>/nova-rp-ai-bot.git
cd nova-rp-ai-bot
npm ci
npm run build
```

Файлы, которых **нет в GitHub** (и не должно быть), перенесите вручную (например, `scp` или WinSCP):
- `.env` — токен бота и `ENCRYPTION_KEY`;
- `data/bot.db` — база: настройки серверов, зашифрованные AI-токены, собранные правила и привязанные ID.
  Без неё бот начнёт с нуля, а если форум закрыт защитой от ботов — не сможет заново собрать правила.
  `ENCRYPTION_KEY` в `.env` должен быть тем же, иначе AI-токены придётся вводить заново.

```bash
mkdir -p data
# скопируйте .env и data/bot.db в папку проекта, затем:
sudo npm install -g pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup        # выполните команду, которую он выведет, — автозапуск после перезагрузки
```

Обновление на сервере: `git pull && npm ci && npm run build && pm2 restart nova-rp-ai`.
**Не запускайте бота одновременно на ПК и на сервере** — Discord будет обрабатывать команды дважды.

## 4. Разработка

```bash
npm run lint     # ESLint
npm run build    # TypeScript → dist/
npm test         # node:test (парсер, правила, поиск, шифрование, лимиты, БД)
npm run check    # всё сразу
```

GitHub Actions (`.github/workflows/ci.yml`) запускает lint + build + тесты на Node 22 и 24.

## Частые проблемы

- **Команды не появились** — глобальная регистрация занимает до нескольких минут; перезапустите Discord.
- **Бот не отвечает в `#ai-помощник`** — не включён MESSAGE CONTENT INTENT.
- **`/setup`: не хватает прав** — выдайте боту Manage Channels и Manage Roles, поднимите его роль выше.
- **«Токен не расшифровывается»** — изменился `ENCRYPTION_KEY`; введите AI-токены заново.
- **`node:sqlite` не найден** — обновите Node.js до 22.13+ (`pkg upgrade nodejs-lts`).
- **Ошибки обновления базы** — смотрите `#ai-логи`: форум мог временно ограничить запросы, увеличьте `SCRAPE_DELAY_MS`.
